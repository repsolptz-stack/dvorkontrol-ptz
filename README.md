# ДворКонтроль ПТЗ

Мобильное веб-приложение для просмотра карты проблем и подготовки обращений по Петрозаводску. Интерфейс можно открыть в обычном браузере или Telegram Web App.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Проверка production-сборки и локальный просмотр:

```sh
npm run build
npm run preview
```

## Сервер заявок

Карта и редактор обращения запускаются без сервера. Для загрузки списка заявок, отправки новых заявок и фотографий создайте `.env` на основе `.env.example` и задайте `VITE_EDGE_BASE` — URL Supabase Edge Functions. На сервере должны быть реализованы функции `list-reports`, `create-report` и `upload-photo`, ожидаемые приложением.

Без настроенного API приложение явно сообщает, что публикация и общий список заявок недоступны. Реализация Edge Functions и конфигурация Supabase в этом репозитории не содержатся.

## Публикация

GitHub Actions собирает проект и выкладывает содержимое `dist/` в GitHub Pages при push в ветку `main`. Для работы заявок добавьте `VITE_EDGE_BASE` в secrets репозитория.
